# ADR-0126: 行動端直式三聯票券場地地圖與響應式投影幾何架構 (Responsive Triptych Portrait Venue Map & Projection Geometry Architecture)

## Status
Accepted

## Context
1. **行動端橫版地圖縮放失真與點擊熱區挑戰**：
   在 `ADR-0124` 建立的互動式場地地圖中，採用了固定 `viewBox="0 0 800 560"` 的橫向票券畫布（主畫布為日本本土四島，左上角為亞洲海外副聯，右下角為沖繩副聯）。在桌面端（`≥ 768px`），此排版自然契合日本列島對角線走向；然而在窄螢幕行動裝置（`< md` / `< 768px`，如 375px–430px 手機寬度）或 `FilterDrawer` 抽屜內，等比例縮放後的畫布高度僅約 260px，兩側伴隨大量空曠海域留白，導致列島本體與各都會區 Livehouse 嚴重縮小，觸控面積不足，產生誤觸或難以點選之痛點。
2. **巡演長征路線跨區拋物航線的連續性要求**：
   若將行動端簡單拆分為 3 個獨立的 DOM 卡片（海外卡、日本卡、沖繩卡），會破壞 `VenueMapCanvas` 內部的單一連續 SVG 座標系統，導致在「巡演長征路線（Tour Journey）」模式下，東京跨海飛往台北、曼谷或那霸之拋物線航線（`flight`）與飛機動畫無法連貫繪製。
3. **沉浸感與非侵入性瀏覽權衡**：
   手機切換至地圖時，若強制自動彈出全螢幕遮罩，會打斷使用者的檢索心流；將地圖以精煉之直式三聯版型於原地展開，並提供顯著的「🔍 全螢幕」按鈕，能兼顧非侵入性閱讀與自主沉浸手勢縮放需求。
4. **沖繩單縣副聯區域之視覺平衡**：
   沖繩本島地理路徑僅約 41px × 25px，若在底部配置過大的副聯框（如 400×140），會導致底部大面積虛白與畫布過度冗長；將其收緊至 240×68 既保留舒適之觸控熱區，又大幅為整體畫布瘦身。

## Decision
1. **極限收窄滿版直式三聯畫布（Ultra-Narrow 540 × 930 Portrait Canvas）**：
   - **桌面端（`≥ 768px`）**：維持現行 800×560 寬版雙副聯經典畫布。
   - **行動端（`< 768px`，包含手機網頁與 `FilterDrawer` 抽屜內）**：純自動響應切換為極限收窄之「直式三聯長條畫布」（`viewBox="0 0 540 930"`，長寬比約 1:1.72 契合手機視窗），左右徹底消除海域空白，列島本體與都會區針點寬度放大近 1.5 倍：
     1. **頂部**：`✈️ OVERSEAS ASIA`（亞洲海外寬幅副聯，寬 500px，收納韓國、台灣、泰國、新加坡）。
     2. **中央**：`🗾 JAPAN MAINLAND`（日本本土四島 46 都道府縣，左右貼邊僅留 8px 邊距）。
     3. **底部**：`🌺 OKINAWA`（沖繩巡演精緻緊湊副聯，寬 240px、高 68px）。
2. **單一連貫 SVG 空間與跨區拋物航線繼承**：
   - 直式畫布保持單一 SVG 空間，直式模式下透過純函式映射直式副聯與日本列島座標（`MAIN_PORTRAIT_OFFSET = { x: -212, y: 260 }`、`OVERSEAS_PORTRAIT_OFFSET = { x: 137, y: 0 }`、`OKINAWA_PORTRAIT_OFFSET = { x: -423, y: 390 }`），使巡演跨區航線與飛機動畫在直式畫布中無縫跨越海外、本土與沖繩。
3. **寬幅票券打孔齒線分割與紙本美學（Full-Width Perforated Ticket Dividers）**：
   - 區域之間採用橫向貫穿 540 寬度的「打孔虛線（Perforation Line ✂）」與等寬字體票頭印章進行視覺分界，嚴格遵守 `DESIGN.md` 紙本票券美學，呈現「三聯折疊式巡演紀念套票」質感。
4. **原地嵌入優先與手動全螢幕控制（In-Place Inline First & Manual Fullscreen Affordance）**：
   - 在行動端（`< 768px`），切換至地圖時預設直接在原地／抽屜內展開，嚴禁強制自動彈出全螢幕遮罩。
   - 地圖右上角維持「🔍 全螢幕」按鈕，歌迷有需要時可自主點擊開啟全螢幕手勢探索（支援手勢雙指縮放與拖曳平移）。
   - 點擊任一縣市原地執行 Spotlight 變焦，頂部浮動高對比票券印章「↩ 返回直式全圖」按鈕。
5. **小尺寸行內微觀場館票卡面板與雙向同步（Mobile Inline Drilldown Panel & Bi-directional Sync）**：
   - 點選縣市時，小尺寸行內地圖正下方同步展開微觀場館清單面板（`map-drilldown-panel`），不再在手機端隱藏。
   - 小尺寸面板設定 `max-h-[360px]`（約 4~5 張票卡高度）支援內部滾動，上方保留地圖視圖與城市膠囊，避免海量場館（如東京都 24+ 場館）過度拉長頁面；展開時溫和平滑微捲動聚焦標題。
   - 支援點擊釘點平滑滾動對齊卡片、點擊卡片直接進入場館詳情，並提供城市膠囊切換與「返回全國（↺）」按鈕。

## Consequences
- **Positive**: 徹底解決小尺寸螢幕下海外與沖繩副聯太小難以點擊的可用性瓶頸，列島觸控面積最大化。
- **Positive**: 沖繩區域大幅緊湊化（高 68px），畫布總高自 1020 縮短至 930，更早看見下方場館排行。
- **Positive**: 取消預設全螢幕彈出，杜絕侵入性彈窗，將操作主控權完整歸還歌迷。
- **Positive**: 小尺寸行內點選縣市後即刻呈現場館票卡與城市膠囊，釘點與清單雙向聯動，補足微觀瀏覽死角。
- **Positive**: 完整繼承 ADR-0124 巡演跨區飛行航線與動畫的視覺連續性。
