# ADR-0133: 參戰足跡紀念明信片純 PNG 離線匯出、全線踏破快照與「參戰紀念」正名架構 (Tour Footprint Postcard Pure PNG Export, Completed Souvenir Snapshot & Live Memorial Architecture)

## Status
已採納 (Accepted)

## Context
在 ADR-0131 與 ADR-0132 中，我們探索了個人巡演票夾參戰足跡明信片（Issue #56）之瀏覽器端短片錄製架構。然而在實測與深度領域審查（/grill-with-docs）中，確認了兩項關鍵產品與體驗決策：

1. **拒絕瀏覽器編碼不可靠性，回歸純前端 100% 穩定輸出**：
   - 瀏覽器原生 `MediaRecorder` 與 Canvas 串流編碼在不同作業系統（Windows / iOS / Android）與不同瀏覽器核心（Blink / WebKit）中存在編碼器支援度落差、後台分頁休眠與影片儲存相容性問題。
   - 歌迷在個人巡演票夾中最核心的需求是：**一鍵存下一張精美、清晰、高對比、隨時可發送至社群（Instagram / Threads / X / LINE）或列印的紀念明信片圖卡**。
   - 依照 `ADR-0123` 拒絕過度工程化原則，果斷收斂並封存影片錄製機制，回歸 100% 穩定、零依賴、零失敗率的 540px 高解析度 PNG 離線匯出。
2. **「遠征踏破」用語校正為歌迷文化正宗「參戰紀念」**：
   - 原型中使用的「遠征踏破」帶有電玩、軍事出征或登山跋涉感，不符 Official 髭男 dism 音樂現場溫暖熱血之氛圍。
   - 樂迷現場文化正宗之用語為「參戰」（Live Attendance），印章正式正名為**「參戰紀念」（LIVE MEMORIAL / 参戦記念 / 참전 기념）**。

## Decision

### 1. 簡化匯出模型：單一純淨「📸 儲存明信片 (PNG)」離線匯出
- 徹底移除 `MediaRecorder` 影片錄影邏輯、轉檔進度條、`<video>` 播放器與 WebM/MP4 檔案下載。
- 彈窗底部操作按鈕收斂為單一高對比主要按鈕：**「📸 儲存明信片 (PNG)」**。
- 遵循 `image-export.js` 離屏排版管線，以 2× 視網膜解析度（寬度 1080px）輸出真透明圓角（`rounded-[8px]`）高對比明信片圖卡。

### 2. 保留即時動態預覽（Live Interactive Journey Preview）
- 彈窗開啟時，依然提供阿肥/休旅車在全日本地圖上奔馳點亮全國的流暢動畫，並保留 `[1×] [2×] [4×]` 倍速切換與 `🔄` 重播按鈕，供歌迷自由賞玩與回味巡演旅程。

### 3. 永遠匯出「全線踏破完成體」（The Completed Souvenir Snapshot）
- 無論歌迷在車車行駛的哪一秒點擊「📸 儲存明信片 (PNG)」，系統在截圖瞬間自動將進度凍結於**「全線踏破完成狀態」**（包含所有場館金色點亮、完整移動路線與蓋妥之紀念印章），截圖完成後無縫恢復先前進度。
- 杜絕因手快按下按鈕而存到「半截路線」或「未蓋章」的半成品，確保歌迷存入相簿的永遠是最完整的珍藏版紀念明信片。

### 4. 正式正名為「參戰紀念（LIVE MEMORIAL）」
- 圓形印章文字正式由生硬的「遠征踏破」改為**「參戰紀念」**，並落實四語在地化對齊：
  - 繁體中文（zh-TW）：**參戰紀念**
  - 日本語（ja）：**参戦記念**
  - English（en）：**LIVE MEMORIAL**
  - 한국어（ko）：**참전 기념**

### 5. 累計距離全面剔除不變式（ADR-0131）
- 持續嚴格恪守「累計遠征距離（~X km）全面剔除」不變式，版面空間聚焦於 47 都道府縣制霸率（X / 47）、總場次與初陣／最新戰歷史紀錄。

## Consequences
- **Positive**: 徹底根除跨瀏覽器影片錄製不穩定性，提供秒級反應、零失敗率的極致安心儲存體驗。
- **Positive**: 始終匯出踏破完成體，確保歌迷珍藏與分享的明信片永遠呈現完整足跡與蓋印儀式。
- **Positive**: 「參戰紀念」用語自然貼切，完美融入髭男歌迷現場共鳴。
- **Positive**: 介面按鈕大幅簡化，聚焦於單一主要行動，消除多餘認知負擔。
- **Compliance**: 完全符合 `ADR-0123` 零後端靜態純粹性、`DESIGN.md` 票券設計美學（radius <= 8px, AAA contrast）與離線 PWA 體驗。
