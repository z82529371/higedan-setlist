# ADR-0080: 現場舞台單據與巡演紀念小卡領域分工暨三主題體系 (Stage Run Sheet Slip and Memorial Setlist Card Architecture)

* **狀態**：已採納 (Accepted)
* **日期**：2026-10-09
* **影響層面**：前台演出票券組件 (`site/src/components/slips.jsx`)、巡演紀念小卡預覽與匯出模態框 (`site/src/components/MemorialCardModal.jsx`)、全站樣式調色盤 (`site/src/style.css`)、核心領域模型 (`CONTEXT.md`)

---

## 背景與動機

1. **社群分享與實體收藏需求**：
   歌迷在查閱 Official 髭男 dism 歷史演唱會歌單時，具有將整場演出曲目匯出為精美圖片、於社群傳播或作個人票券收藏之強烈需求。

2. **互動母單與靜態小卡的職責衝突**：
   在探索階段，曾嘗試將密閉式紀念小卡風格或暗黑混音台外殼直接套用於網頁主畫面上，導致「曲目超連結跳轉」、「雙場對比」、「曲目更換 Diff」、「專輯分佈」等動態抽屜展開時版面破碎、格線拉扯，失去了工作母單的流暢感。

3. **匯出效能瓶頸與高度截斷缺陷**：
   先前圖片產生因字體全量解析耗時超過 15 秒；且在單欄長篇歌單（超過 12 首）匯出時，容器可視高度受限導致下半段與安可曲目反黑截斷。

4. **曲目行徽章視覺噪音**：
   在曲目行內塞入「自彈自唱」、「點歌」、「初披露」等多重色彩小徽章，破壞了歌單曲目排版的字體韻律，且「初披露」與全站「新歌（以歌 × 巡演為單位）」領域定義衝突。

---

## 決策與架構規範

### 1. 舞台工作單據（ShowSlip）與紀念小卡（MemorialCardModal）領域分工
- **現場舞台單據（Stage Run Sheet Slip）**：
  - 作為網頁主視圖的互動型工作母單，採用直向票券流。
  - 配色嚴格遵循官方網站 `service.css`：淺色模式採用「經典純白卡 `#ffffff`（`--color-card`）」搭配「官網背景紙灰 `#e6e6e6`（`--color-paper`）」與「墨黑字 `#000000`（`--color-ink`）」，享有最高閱讀對比與清爽現代感。
  - 承載動態互動任務（曲目與場地跳轉、雙場對比、專輯構成、官方一手公告來源），不硬塞封閉式裝飾。
- **巡演紀念小卡（Memorial Setlist Card）**：
  - 獨立彈窗載體（Modal），專注於靜態美學與圖片分享。
  - 具備官方認證標頭、裝飾條碼、現場朱印與獨立佈局控制。

### 2. 紀念小卡三主題體系與 Session 級別記憶
紀念小卡脫離網頁主配色約束，具備獨立的三主題調色系統：
- **📄 復古手感紙（Vintage，預設）**：
  - 底色：暖象牙米紙 `#fcfaf2`
  - 邊框：復古紙邊 `#d6cebf`
  - 序號：焦茶金 `#78350f`
  - 安可框：淡金底框 `#f4eedf`
  - 朱印：深紅印章 `#b91c1c`
- **✉️ 經典純白卡（White）**：
  - 底色：純白票券 `#ffffff`
  - 邊框：現代冷灰 `#d1d5db`
  - 序號：深邃墨黑 `#111827`
  - 安可框：極淡灰底框 `#f9fafb`
  - 朱印：正紅印章 `#dc2626`
- **🖤 暗夜舞台金（Noir）**：
  - 底色：暗夜舞台 `#111319`
  - 邊框：黑曜邊框 `#2e3444`
  - 序號：琥珀金光 `#d49a00`
  - 安可框：曜黑底框 `#181a23`
  - 朱印：金漆印章 `#d49a00`

**Session 記憶機制**：
透過模組級狀態在使用者單次瀏覽中自動記憶主題選擇，切換場次查看小卡時持續生效。

### 3. 百毫秒極速 2x 原寸無損 PNG 匯出架構
- 啟用 `skipFonts: true` 規避 `html-to-image` 耗時的字體重複拉取與 Base64 轉換，將圖片生成時間從 15 秒驟降至 < 100 毫秒。
- 注入精確的 `backgroundColor`（依當前主題動態注入 `#fcfaf2` / `#ffffff` / `#111319`），消除邊緣透明滲漏。
- 動態計算 `actualWidth` 與 `actualHeight`（`scrollWidth` / `scrollHeight`），強制作為 canvas 原寸寬高，保證 M1～M20+ 與所有安可曲 100% 完整收錄無任何黑屏或高度裁切。

### 4. 曲目行純淨化（Clean Track Rows）
- 全面剔除網頁單據與紀念小卡曲名旁的「自彈自唱」、「點歌」、「初披露」等行內彩色小徽章。
- 曲目行回歸「序號 + 曲名 + 必要 note 附註」的俐落字體排版；特殊狀態由卡片左上方頂部卡籤（TabBar）及既有備註呈現，維持視覺乾淨專注。

---

## 效益

1. **視覺層次分明**：網頁主母單維持高對比純白，乾淨專業；紀念小卡提供三種特色實體風格，滿足收藏樂趣。
2. **分享體驗卓越**：百毫秒極速產出 2x 高解析 PNG，且全篇曲目保證完整，杜絕截斷 bug。
3. **消除視覺噪音**：拔除零碎行內徽章，大幅降低歌單閱讀的認知負荷。
