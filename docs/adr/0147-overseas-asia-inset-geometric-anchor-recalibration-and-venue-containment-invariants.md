# ADR-0147: 海外副聯多國幾何錨點重新校準與全庫場館地圖邊界不變式門禁 (Overseas Asia Inset Geometric Anchor Recalibration & Venue Containment Invariants)

- **日期**：2026-11-10
- **決策者**：Core Development & Design Team
- **相關文件**：`ADR-0124`, `ADR-0126`, `ADR-0128`, `CONTEXT.md`, `CODING_STANDARDS.md`, `GLOSSARY.md`

## 1. 背景與問題陳述 (Context & Problem Statement)

在 `ADR-0124` 與 `ADR-0126` 中，系統為解決跨國比例尺失衡問題，於互動式場地地圖（`<VenueMapCanvas />`）左上角建立了「✈️ 海外亞洲副聯插頁（Overseas Asia Inset）」，收納韓國（首爾／高陽）、台灣（台北）、泰國（曼谷）、新加坡 4 國 5 城 6 館。

然而，在實際視覺探索與地理審查時，樂迷發現了嚴重的視覺錯位反常：
1. **台北小巨蛋視覺南偏**：
   在 `data/venue-profiles.json` 中，台北小巨蛋的 WGS84 座標（`lat: 25.0507, lng: 121.55`，台北市松山區南京東路四段2號）數值正確。但在 `site/src/lib/venue-map.js` 的 `OVERSEAS_COUNTRY_ANCHORS` 中，台灣基準點卻被定義為：
   ```javascript
   台灣: { baseLat: 25.05, baseLng: 121.55, cx: 198, cy: 96, scale: 28 }
   ```
   台灣島向量輪廓（`japan-map-paths.js`）的南北範圍為 `y = 61.2`（富貴角）至 `y = 118.2`（鵝鑾鼻），中心在 `cy = 90.8`。上述錨點將北緯 `25.05°`（台北小巨蛋）強制對齊至 `cy = 96`，直接將台北小巨蛋釘在**台灣中南部（台南／嘉義一帶）**，嚴重背離地理現實。
2. **韓國首爾／高陽視覺南偏**：
   韓國 SVG 路徑為南韓全境（`y = 52.9` 停戰線 38°N 至 `y = 128.5` 濟州島）。原本之錨點將首爾（`37.55°N`）設定於 `cy = 86`，導致位於南韓西北部頂端（應在 `y ≈ 62`）的首爾與高陽 3 處場館被畫在南韓中部（大田／大邱一帶）。
3. **缺乏全庫場館投影地圖邊界之自動化門禁**：
   先前測試套件僅驗證投影點落在寬泛的外部副聯框（`x ∈ [16, 266], y ∈ [16, 211]`），缺乏細粒度的「行政分區與國土輪廓邊界包含斷言」，導致投影幾何出現偏移時 CI 無法及時報警攔截。

## 2. 決策方案 (Decision)

### 2.1 廢止局部寫死與單一比例尺，確立「區域標準緯線雙軸自適應投影算法（Local Standard Parallel Dual-Axis Adaptive Projection）」

全面廢除在海外副聯中借用日本本州 $\cos(36^\circ)$ 的粗糙作法，回歸正統地圖學投影方程式，以各國真實大地極端點推導專屬中心緯度 $\phi_0$、東西橫向比例尺 $S_x$ 與南北縱向比例尺 $S_y$：
$$x = c_x + (\lambda - \lambda_0) \cdot \cos(\phi_0) \cdot S_x$$
$$y = c_y - (\phi - \phi_0) \cdot S_y$$

1. **台灣（Taiwan）**：
   - 國土極值：南北緯 21.902°N（鵝鑾鼻）～ 25.298°N（富貴角），跨度 3.396° 對應 SVG 高度 57px，解出 $S_y = 16.7845$；東西經 120.035°E（七股）～ 121.998°E（三貂角），解出 $S_x = 13.6200$。
   - 大地基準中心：$\phi_0 = 23.60^\circ$（$\cos 23.60^\circ \approx 0.9164$），$\lambda_0 = 121.0165^\circ\text{E}$。
   - SVG 錨點中心：`cx = 194.85, cy = 89.70`。
   - **實證效果**：台北小巨蛋（`25.0507°N, 121.55°E`）投影點精準降落在 `(201.51, 65.35)`（淡水 196.0 與基隆 207.1 之間的台北盆地核心，距富貴角約 25 公里，完全契合地理真實）；若未來加入高雄巨蛋（`22.62°N, 120.30°E`），落點自然出現在 `(185.91, 106.15)`（南台灣西南部海灣），全島相對比例完美自適應。

2. **韓國（Republic of Korea）**：
   - 國土極值：本土北緯 34.30°N（海南）～ 38.00°N（停戰線 38°N），跨度 3.70° 對應 SVG 高度 58.5px，解出 $S_y = 15.8108$；東西經 126.30°E（仁川）～ 129.40°E（浦項），解出 $S_x = 13.1581$。
   - 大地基準中心：$\phi_0 = 36.15^\circ$（$\cos 36.15^\circ \approx 0.8074$），$\lambda_0 = 127.85^\circ\text{E}$。
   - SVG 錨點中心：`cx = 77.70, cy = 82.15`。
   - **實證效果**：首爾 KSPO DOME 落在 `(70.02, 60.50)`、Understage 落在 `(68.68, 60.23)`、高陽 KINTEX 落在 `(65.97, 58.13)`，精準群聚於南韓西北首爾圈，高陽自然位於首爾西北側。

3. **泰國（曼谷灣頭）與新加坡（島國中心）**：
   - 泰國採用 $\phi_0 = 13.73^\circ$（曼谷灣頂端 `80.89, 161.75`）；新加坡採用 $\phi_0 = 1.35^\circ$（島國中心 `193.32, 162.31`）。

### 2.2 雙向響應式長寬轉換無縫繼承

依據 `ADR-0126` 之三聯直式地圖（`projectPointToLayout`），海外副聯在寬版（`800×560`）與直式長條版（`540×930`）之間僅採用純線性平移向量（`OVERSEAS_PORTRAIT_OFFSET = { x: 137, y: 0 }`）。因此本幾何校準在桌機與行動裝置上 100% 保持完全等價之精確落點。

### 2.3 全庫 347 處實體場館地圖邊界不變式門禁（Venue Containment Invariant Gate）

在 `site/tests/invariants/venue-profiles.test.js` 與 `site/tests/pipeline/venue-map.test.js` 中建立雙層防禦：
1. **全庫 347 館 100% 邊界包含**：
   自動解析 47 都道府縣與 4 海外國家的 SVG Path 幾何邊界，斷言全庫 347 處實體場館經過 `projectLatLngToSvg` 後的 `(x, y)` 座標，全部嚴格落在所屬區域的邊界框（含 12px 沿海 livehouse 容差）之內。
2. **次國家級（Sub-national）關鍵落點斷言**：
   - 台北小巨蛋強制斷言 `pt.y <= 75`（北台灣），嚴禁落入南台灣。
   - 首爾與高陽場館強制斷言 `pt.y <= 68`（西北部），嚴禁落入中部大田。
   - 跨海巡演航線（`buildJourneySequence`）從東京／福岡直飛台北時，弧線起迄點精確銜接北台灣，消除飛往南部的怪異視覺。

## 3. 結果與影響 (Consequences)

- **正面影響 (Positive)**：
  - 徹底解決了台灣歌迷打開地圖「台北小巨蛋長在台南」的強烈認知違和，還原台北正北端的真實地理脈絡。
  - 首爾與高陽場館回歸西北首爾圈，東南側釜山外海空間完整淨空。
  - 全庫 347 處實體場館（日本本土四島 340 館、沖繩 1 館、海外 6 館）全面通過 100% 向量邊界檢驗，建立不可破壞的自動化回歸防線。
- **負面影響／取捨 (Trade-offs)**：
  - 各國簡化 SVG 輪廓非高密度 GIS 測繪，比例尺採用等距圓柱線性擬合，主要追求票券美學下的相對拓撲真實性，極端局部距離（< 1km）仍需依賴 Google Maps 外部連結導航。
