# 場館命名改為中文優先

場館（venue）名稱的命名原則從「一律官方英文原名」（ADR 0008 時期）改為 **中文優先**：能用中文的旨先使用中文，沒有對應中文才退回官方英文。

中文取法：
- 日式場館一概翻成中文——場館地點與設施類型中文化，如 仙台サンプラザホール → **仙台太陽廣場會館**、大阪城ホール → **大阪城會館**、千葉市蘇我スポーツ公園 → **千葉市蘇我體育公園**。
- 海外有約定譯名者也用中文，如 **台北小巨蛋**（Taipei Arena）、**高尺天空巨蛋**（KSPO DOME）、**星宇表演藝術中心**（星宇表演藝術中心 THE STAR THEATRE）。
- 品牌名與劇場暱稱保留原文，嵌在中文名內：如 **福岡Zepp**、**iichiko 大劇場**、**札幌文化藝術劇場 hitaru**、**橫濱K-Arena**。
- 唯一沒有中文名才用官方英文，如 **UOB LIVE**。

理由：場次標頭與選擇器以中文為主要閱讀語言，中文場館名比英文或日文片假名都更易讀；proper name（Zepp、hitaru、K-Arena）屬商標性詞彙，不翻譯。

後端資料、前端三行場次標示與搜尋提示（placeholder）同步以中文場館名為準。
