# ADR-0059: 整輪巡演固定翻唱曲目納入共識模板規範

## Status
Accepted

## Context

1. **翻唱曲與歌曲主檔之界線（[ADR-0055](0055-cover-songs-title-track-boundary.md)）**：
   - ADR-0055 確立非髭男原創之翻唱曲目（如西洋經典、J-POP 翻唱、傳統頌歌）絕對不登錄於 `data/songs.json` 原創歌曲主檔庫，僅以 `"title": "曲名 [原唱歌手]"` 軌記錄。
   - ADR-0055 當時針對之情境主要為「單一場次突發或限定場次之翻唱」（如神戶場限定之《Don't Stop Me Now [Queen]》），此類個別場次翻唱曲僅於該場次之 `diff.insert` 呈現。
2. **整輪巡演常設翻唱曲之共識模板矛盾**：
   - 在 2017 年秋冬全國專場巡演《Official髭男dism one-man tour 2017 -winter-》（全 8 場）中，樂團於整輪巡演之每一場次均固定安排了小澤健二名曲《ぼくらが旅に出る理由》之完整翻唱，且演出順序固定為 M6（接於《夕暮れ沿い》之後、《ゼロのままでいられたら》之前）。
   - 若機械式地將所有翻唱曲排除於巡演模板外，會導致該巡演全部 8 場演出每一場都必須重複宣告冗餘的 `diff.insert`，且無法反映巡演整體真正的演出結構與共識曲序。
   - 此外，因 LiveFans 各場次回報者資料品質不一（部分場次錯記於第 8 首，部分場次缺索引導致 DOM 錯位），若不將其下沉模板並鎖定，爬蟲重新計算時將不斷產生虛假差異。

---

## Decision

1. **整輪固定常設翻唱曲允許下沉進入巡演共識模板 `templateSetlist`**：
   - 若某翻唱曲目為該巡演之固定安排（於全場次或 $\ge 50\%$ 場次常設演出），允許直接作為 `title` 軌（無 `songId`）編入 `templateSetlist` 中：
     ```json
     {
       "order": 6,
       "encore": false,
       "title": "ぼくらが旅に出る理由 [小沢健二]"
     }
     ```
   - 模板中的此類軌道維持不包含 `songId`，因此依然**嚴格遵守 ADR-0055**，絕不污染 `data/songs.json` 主檔庫或全站原創歌曲統計。
2. **《one-man tour 2017 -winter-》歌單淨化與全場次鎖定**：
   - 將《ぼくらが旅に出る理由 [小沢健二]》固化於模板第 6 軌（M6）。
   - 松江、水戶、仙台、福岡、大阪、神戶、名古屋等 7 場演出之曲序與模板 100% 精準吻合，簡化為極致之 `diff: {}`。
   - 東京赤坂最終場保留原版差異（前段《始まりの朝》與《愛なんだが…》對調、《夕暮れ沿い》不插電版、《ゼロのままでいられたら》自彈自唱、安可追加《What's Going On?》）。
   - 本巡演全 8 場演出全數標記 `"locked": true`，防止 LiveFans 雜訊曲序覆寫。

---

## Consequences

- 消除 8 場巡演中大量重複的 `diff.insert`，資料結構大幅瘦身且語意精確。
- 確立「固定常設翻唱下沉模板」與「單場限定翻唱留於差異」之清晰架構原則。
- 前端與管線對 `templateSetlist` 中之 `title` 軌運作流暢，渲染曲序真實無誤。
