# ADR-0096: 日期智能檢索、日曆懸浮視窗與日期有場次受限交互規範 (Date Search and Calendar Modal Architecture)

## 狀態
已採納 (Accepted)

## 脈絡 (Context)
在先前版本中，使用者可透過全域搜尋框檢索「歌曲名稱」、「巡演/事件名稱」與「演出場館」。然而在回溯巡演或考證特定歷史場次時，以「日期」作為線索的檢索心智（例如輸入年份 `2024`、年月 `2024-09`、特定日期 `09-21` 或完整 `2024-09-21`）具備強大需求。

同時，使用者明確要求：
1. **日期可搜尋**：全域搜尋框必須辨識日期格式，精準列出場次候選名單，點擊可直接跳轉場次票券（`ShowSlip`）。
2. **日曆懸浮視窗（Calendar Modal）**：於搜尋框配置專屬 📅 日曆按鈕，喚起乾淨簡潔的日曆視窗。
3. **僅有場次之日期開放點選**：日曆元件嚴格遵循「只有當天有公開演出的日期才可點選」的約束，無演出的日期呈現禁選置灰；當日具備演出者標註小圓點或演出徽章，點選後立即導航至該場次（若同日有多場演出，則呈現選單讓使用者挑選）。

## 決定 (Decision)

1. **搜尋框日期語義擴展（Date-Aware SearchBox）**：
   - 擴充 `SearchBox.jsx` 之 `needle` 解析管線。若輸入包含數字與連字號/斜線/句點（如 `2024-09-21`、`2024/09/21`、`2024.09.21`、`20240921`、`09-21`、`2024-09` 等），自動比對全站 520+ 歷史場次。
   - 搜尋下拉清單新增專屬「📅 場次日期」分組桶（`matchedShows`），優先呈現日期、場次所屬巡演/活動與場館，點擊直接觸發 `onSelectShow(showId)`。

2. **日曆懸浮視窗組件（`CalendarModal.jsx`）**：
   - 設計專屬日曆視窗，支援年份與月份切換（覆蓋 2012–2026 年）。
   - **空演出月份智能跳過機制（Empty-Month Skip Navigation）**：
     - 月份步進切換按鈕（`◀` / `▶`）嚴格鎖定於全檔案庫實際有公開演出的 129 個月份之間連鎖跳轉，直接掠過無演出的空白月份（例如 2012 年 1~6 月或樂團休息期）。
     - 年份切換時，月份選單與預設月份僅列出「該年度實際有演出的月份」，杜絕使用者翻閱到「0場次」的空白月曆。
   - 日曆日格（Day Cell）依據當月場次狀態進行條件約束：
     - **有場次之日期**：呈現高亮背景（琥珀金/樂團色）、醒目字體與演出計數標記，允許 Hover 與點擊。
     - **無場次之日期**：透明/微置灰、禁用游標（`cursor-not-allowed`、`pointer-events-none`），杜絕無效點擊。
   - 點擊有場次之日期：
     - 若該日僅 1 場演出：直接調用 `onSelectShow(showId)` 並關閉視窗。
     - 若該日有 $\ge 2$ 場演出（如早期 Free Live 分 1部 / 2部）：彈出展開清單讓使用者點選特定部次。

3. **觸發入口與人體工學（Entrypoints & Ergonomics）**：
   - 在桌面端常駐搜尋框、首頁 Spotlight 搜尋框以及手機端全螢幕搜尋視窗右側，均配置「📅 日曆」圖標按鈕，一鍵喚起 `CalendarModal`。
   - 視窗支援 ESC 鍵關閉、點擊遮罩外關閉，並完全適配行動端與桌面端視窗。

4. **搜尋框外觀純粹化（SearchBox Visual Simplification）**：
   - **移除左側顯眼文字標籤**：移除桌面端輸入框左側生硬的「全域搜尋」實體字樣，轉為無障礙隱藏標籤（`<label className="sr-only">搜尋</label>`），輸入框內左側內嵌精緻向量放大鏡 `🔍`，搭配寬裕內距（`pl-8`）與聚焦光環。
   - **首頁聚光燈搜尋單層化（Single-Layer Spotlight）**：移除首頁包覆在搜尋框外側的多餘雙層卡片厚重外框，改由 `SearchBox` 原生大尺寸樣式（`size="lg"`、高度 `py-3 sm:py-3.5`、字級 `16px`、圓角 `rounded-[6px]`、立體微陰影）直接呈現，提升呼吸感與現代感。

## 後果 (Consequences)
- **正面效益**：
  - 打通「歌曲、單元、場館、日期」四位一體的完整全域檢索鏈。
  - 日曆受限交互精準傳遞樂團 2012–2026 演出的時空分佈，完全杜絕空點擊。
- **負面效益／注意事項**：
  - 需確保多場次日期（全站 21 個特殊同日多場次）的選單體驗流暢不突兀。
