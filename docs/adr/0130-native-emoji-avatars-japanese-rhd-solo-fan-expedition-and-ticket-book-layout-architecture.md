# ADR-0130: 純原生 Emoji 吉祥物、日本右駕自駕遠征與票夾高密度版面架構 (Native Emoji Avatars, Japanese RHD Solo Fan Expedition & Ticket Book High-Density Layout Architecture)

## Status
已採納 (Accepted)

## Context
在 ADR-0129 確立了四位團員動物吉祥物（🐨 藤原聡、🐱 小笹大輔、🦍 楢﨑誠、🐻 松浦匡希）象徵對應與三態巡演狀態機（`moving`、`stay`、`arrived` / `final`）後，在進入元件實作與個人票夾（`TicketBookPage`）端到端落地階段時，產生了四項需進一步收斂的領域設計議題：

1. **視覺負擔與純粹性**：原草案構想手繪複雜 SVG 樂器（琴鍵、吉他、貝斯、鼓棒）。然而在高密度地圖縮小呈現下，過多手繪線條容易淪為視覺噪點；相較之下，純原生系統 Emoji（🦍 🐨 🐱 🐻）具備天然辨識度、0 KB 增量預算，且與票券復古風格完美契合。
2. **座駕文化與日本右駕（RHD）保真度**：原先載具未明定駕駛席位與前進朝向，導致 Emoji 在載具上出現朝向側面或逆向行駛之違和感；且日本車輛為右駕（Right-Hand Drive），在樂團文化中共識由貝斯手（🦍 楢﨑誠）負責開車。
3. **個人參戰足跡主體性（Superseding ADR-0129 局部條款）**：ADR-0129 原草案曾提「個人票夾地圖嚴格排除載具」。然而在實測中，歌迷在個人票夾中同樣渴望看到自己多年參戰的移動軌跡與行車動畫；但若車上載著樂團四人會造成「究竟是誰在遠征」的主客體混淆。此外，個人車頂上已坐著歌迷時，左下角若再疊放一塊單獨的狀態小卡（`BandEnsembleHUD`），會造成嚴重的資訊重複與畫面遮蔽。
4. **個人票夾版面密度與縱向留白浪費**：個人票夾內的「生涯里程碑（Career Milestones）」外層被厚重的卡片黑框包覆，與票夾邊界形成雙重框線；且每張已登錄票券底部的「🎨 儲存紀念票根」按鈕獨佔一行，造成卡片縱向長度膨脹。

## Decision

### 1. 純原生系統 Emoji 選型（Pure Native Emojis）
- 全面廢除手繪複雜樂器裝飾，以純原生系統 Emoji 作為四位團員吉祥物核心：
  - 🦍 **楢﨑誠**（Gorilla / 貝斯手開車領航）
  - 🐨 **藤原聡**（Koala / 主唱鋼琴）
  - 🐱 **小笹大輔**（Cat / 吉他手）
  - 🐻 **松浦匡希**（Bear / 鼓手）
- 元件封裝於 `BandAnimalAvatars.jsx`，以 `<GorillaAvatar>`、`<KoalaAvatar>`、`<CatAvatar>`、`<BearAvatar>` 與統一分發器 `<BandMemberAvatar>` 輸出，零額外點陣圖檔與 SVG 複雜路徑，達到極致效能與 100% 離線可用性。

### 2. 日本右駕席位規範與車頭方位鎖定
- **巡演廂型車（`TourVan3D`）席位**：
  - 車體擴充至 Chibi 巡演車規格（`36 × 20`），配置開篷觀景艙甲板與前後 13px、左右 12.4px 開闊座距。
  - **右側駕駛席（$y = +6.2$）**：🦍 **楢﨑誠**（日本 RHD 右駕司機）。
  - **左側副駕席（$y = -6.2$）**：🐨 **藤原聡**。
  - **後排席位**：🐱 **小笹大輔**（左）與 🐻 **松浦匡希**（右）。
- **車頭行進方位鎖定**：4 位 Emoji 視線旋轉 180° 改為 `rotate(-90)`，頭部與視線精確朝向車頭道路前方（$+x$ 軸方向）。
- **巡演專機（`TourAirplane3D`）席位**：4 位 Emoji 沿機身長軸自前向後排列（🦍 ➔ 🐨 ➔ 🐱 ➔ 🐻），同樣以 `rotate(-90)` 專注面向航向正前方。
- **近距離航向平滑化**：在 `journey-playback.js` 中，對直線距離小於 15px 之微小跳點（如早期島根縣內公演），移除強制曲線偏移，避免載具原地打轉。

### 3. 個人自駕遠征主體性（Solo Fan Rider）與冗餘 HUD 省略
- **歌迷自駕遠征**：在個人參戰足跡（`TicketBookFootprintMap`）中，全面以 **😎 墨鏡歌迷** 取代樂團四人：
  - 廂型車上親自入座日本右駕駕駛席（`x: 4, y: 6.2`，字級 11.5px，`rotate(-90)`），象徵歌迷開車遠征全日本參戰。
  - 專機上入座最前方機長領航席（`x: 13.5, y: 0`，字級 11px，`rotate(-90)`），象徵歌迷搭機遠征跨海參戰。
- **省略冗餘 Ensemble 狀態小卡**：在個人模式（`isPersonal: true`）下，地圖左下角**嚴格不渲染 `BandEnsembleHUD` 狀態小卡**；保留實用的場次票根卡（`journey-hud-card`），確保點擊即可流暢查看單場完整歌單，畫面保持清爽通透。

### 4. 票夾高密度版面整合（Ticket Book High-Density Layout）
- **生涯里程碑無框整合**：去除 `TicketBookMilestoneDashboard` 的硬黑外框、卡片背景色與四週內距，轉化為與票夾背景無縫融合的無框區塊（`className="mb-6"`），寬度與票夾打孔虛線完全齊平。
- **儲存紀念票根移入頂部操作列**：將票券卡片底部的「`🎨 儲存紀念票根`」按鈕移入頂部 Header 右側操作區，以膠囊按鈕（Pill Button）樣式與「`🎫 查看票根 →`」及「`🗑️ 移出票夾`」同列並行，徹底刪除底部獨立行，消除多餘縱向留白。

## Consequences
- **Positive**: 視覺極致純粹，純原生 Emoji 大幅降低認知負荷，完全消除樂器繪製帶來的線條噪點。
- **Positive**: 嚴格體現日本道路文化與樂團自駕傳統（貝斯手開車、右駕規範、視線朝前）。
- **Positive**: 完美維護個人票夾之主體性，歌迷化身 😎 墨鏡自駕遠征，且地圖省去重複狀態方塊。
- **Positive**: 票夾版面密度提升，單張票券卡片高度緊湊，瀏覽時一覽無遺。
- **Compliance**: 嚴格遵守 `ADR-0123` 零後端靜態純粹性、`DESIGN.md` 高對比墨水規範與 `AGENTS.md` 歷史記錄不可篡改原則。
