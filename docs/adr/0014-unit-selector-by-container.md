# 單元選擇器按容器分群（巡演／事件），事件排用藤紫

show 查詢列的單元選擇器不再把所有單元混在一個 flex 列、也不以「非專場才標」的 type badge 區別，改為**按容器分成兩排**：巡演一排在上一排、事件一排在下，各排同色系，按鈕上不掛 type badge。

- 巡演排沿用既有的深墨藍 pill。
- 事件排以新增的藤紫（`--occasion: #6d5a99`）為 accent、淡紫 wash 為 hover；上排與下排以 4px 縱距相接。
- 執行方式：`.tour-tabs`／`.event-tabs` 各自宣告 `--unit-accent`／`--unit-wash`，`.query-tab` 以 `var(--unit-accent, var(--ink))` 引用——預設（查詢方向列）仍是深墨藍。
- 演出類型的 type badge（音樂祭／對バン）仍保留在歌曲全史、場地全史等**標頭**位置，僅從選擇器按鈕移除。

理由：音樂祭、對バン 是「演出類型」，巡演、事件是「收錄容器」，把兩條軸混在同一個 button rect 上讓「音樂祭 vs 巡演」無從比較；而在資料中只有「專場」跨容器（巡演全場是專場、單發 live 也是專場），因此唯一能穩定切群的軸是容器。分兩排後，即便未來單元變多，群界線也不消蝕。事件排選藤紫是取全站尚未使用的第二冷色，避免與既有 kind 語彙（新歌金、自彈自唱 teal、點歌紅、未發表紫）串味。
