# ADR-0081: 全站正名、官方翹鬍子品牌識別與頂部 Micro-Hero 數據引導架構 (Brand Identity Normalization and Micro-Hero Architecture)

* **狀態**：已採納 (Accepted)
* **日期**：2026-10-09
* **影響層面**：首頁 HTML 標籤 (`site/index.html`)、前台首頁 Header 組件 (`site/src/App.jsx`)、靜態圖標資源 (`site/public/favicon.*`)、核心領域模型 (`CONTEXT.md`)

---

## 背景與動機

1. **舊標籤之地域侷限與認知落差**：
   專案早期在首頁 `<title>` 與 `<meta name="description">` 中標記為「亞洲巡演曲目清單」。然而隨著資料庫全面收錄 2012 年地下獨立時期至 2026 年最新巨蛋巡演（全庫 300+ 場演出、涵蓋日本各大 Arena/Hall 巡演、學園祭、音樂祭、店家活動與電視演出），「亞洲巡演」已嚴重限縮檔案庫規模，造成新訪客誤以為僅收錄海外幾場演出。

2. **文藝煽情語句與資料庫嚴肅性衝突**：
   原頁首大標題使用「那一晚，他們唱了什麼。」，屬於情緒煽動型文案，不符合資料庫工具所應具備的公信力、嚴謹度與長期可信度。

3. **獨立 Landing Page 的破壞性**：
   在使用者研究中，評估過是否需增設獨立 Landing Page 作為首頁門面。但此舉會強行阻斷使用者的即時探索需求，增加額外點擊跳轉成本，違反 ADR-0070 所奠定的「即時滿足、首頁即直出最新重大巡演」的核心鐵律。

4. **品牌圖標缺失與非官方幾何圖樣**：
   原瀏覽器標籤頁缺少能代表 Official 髭男 dism 精神的標誌性圖標。先前使用通用剪影幾何鬍子，無法精準傳達官方微笑翹鬍子的品牌調性。

---

## 決策與架構規範

### 1. 全站正名與全域 Meta 語意升格
- 首頁 `<title>` 正名為：
  `Official髭男dism Setlist 檔案庫｜場次與曲目演出紀錄`
- 首頁 `<meta name="description">` 正名為：
  `Official髭男dism 演出場次與曲目清單檔案庫：收錄 2012 年至今完整現場足跡，提供場次查歌單與歌曲查場次雙向檢索。`
- 嚴格拔除所有「亞洲巡演」侷限性字眼，對齊全域編年史檔案庫定位。

### 2. 頁首 Micro-Hero 數據膠囊列架構
徹底捨棄獨立 Landing Page 與煽情語句，在單欄聚焦流頂部導入高度緊湊（緊湊垂直留白）的 Micro-Hero：
- **等寬英文眉標**：`LIVE PERFORMANCE & SETLIST ARCHIVE`，維持國際音樂檔案庫的俐落感。
- **主標題**：`Official髭男dism Setlist 檔案庫`，品牌赭金強調關鍵字。
- **副標題**：`場次與曲目雙向檔案庫。收錄 2012 年地下獨立時期至當前巨蛋巡演的完整現場足跡。`
- **Micro-Hero 數據膠囊列**：平鋪一行 5 顆即時動態統計標籤，不佔版面且在進站 0.5 秒內建立權威感：
  1. `📅 2012–2026 年`
  2. `🎫 {totalAllShows} 場公開演出`
  3. `🎭 8 大演出型態`
  4. `🎵 {allUsedSongs.length} 首原創曲目`
  5. `📍 {allVenues.length} 處歷史場館`

### 3. 官方標準微笑翹鬍子 Favicon 向量體系
- 精準擷取 Official 髭男 dism 官方標準造型（對稱微揚之翹鬍子輪廓）。
- 色彩對齊官方標準：底色採用芥末暖黃 `#ffc400`，圖標主體採用深黑 `#121212`。
- 建立全尺寸圖標鏈以支援各式現代客戶端：
  - `site/public/favicon.svg`（現代向量無損）
  - `site/public/favicon.ico`（傳統瀏覽器相容）
  - `site/public/apple-touch-icon.png`（iOS / Safari 書籤 180x180）
  - `site/public/favicon-32x32.png`、`site/public/favicon-16x16.png`（桌面瀏覽器分頁）

---

## 效益

1. **公信力與專業感**：徹底拔除煽情標題與狹隘標籤，呈現具備官方文獻質感的音樂現場資料庫。
2. **極速載入與零認知負擔**：Micro-Hero 兼顧了品牌展示與資料規模感，且完全不干擾下方票券檢索。
3. **品牌辨識度頂級化**：官方同款微笑翹鬍子圖標在瀏覽器分頁、書籤及行動桌面皆清晰醒目。
