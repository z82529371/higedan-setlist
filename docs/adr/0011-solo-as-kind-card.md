# 自彈自唱升格為 kind 卡片標籤（SOLO）

演出曲目新增 `satoshi-solo` 特別標籤（展示文字「自彈自唱」），以紙籤卡片呈現，與 request、unreleased、premiere 同為「卡片級特別標籤」家族；歌的全史檢視對應顯示「自彈自唱」小徽章。標籤名帶 performer（藤原聡）語意，與「他人 solo」切分。

前身是 Four-Re 模板上 Subtitle 的 `note: "自彈自唱"`。原判版本差異（note）與特別標籤（kind）兩層：note 收「這一場怎麼唱」的表演變異而非歌曲性質，自彈自唱本屬 note。但 Owner 評估後決定將它升格為卡片級標籤——藤原の自彈自唱是全曲性質的演出樣態、非單場變異，且值得與未發行、新歌同級的視覺提示。

此為**例外升格，非通則**：其餘版本差異（アコースティックver、點歌段部分演唱…）仍應留在 note。往後若有新的演出樣態想升格，須比照此案由 Owner 明確認定，避免 kind 因各種細微變異而膨脹。
