# ADR-0091: 日系 5mm 方眼手帳筆記本與檯燈聚光背景架構 (Japanese 5mm Graph Notebook and Desk Lamp Ambient Glow Architecture)

## 狀態
已通過 (Accepted)

## 背景 (Context)
在先前版本中，全站背景經歷了幾何圓點陣列與純手感紙質的探索。然而，單據卡片上方設計有「實體手撕和紙膠帶（`SLIP_TAPE`）」：
1. **擬物故事感契合（Notebook Scrapbook Metaphor）**：使用者明確指出希望背景呈現「筆記本的那種感覺」。在真實世界中，手撕和紙膠帶最自然、最經典的承載物，正是將演唱會門票、舞台歌單粘貼在歌迷的「現場手帳筆記本」或樂團舞台監督的「巡演方格工作筆記」內頁上。
2. **方眼紙的美學秩序感**：相較於科技感圓點，日系 5mm 方眼格（Graph Paper / 方眼ノート，如 Midori MD Notebook、Kokuyo Campus 方眼紙）線條內斂、細緻且具備人文手作氣質，能為中央票券提供絕佳的襯托。

---

## 決策 (Decision)

### 1. 日系 5mm 方眼手帳格線 (`.notebook-grid`)
- 滿版無縫平鋪 20px × 20px（接近標準 5mm 手帳方格）微細格線：
  - 運用 CSS `linear-gradient` 繪製 1px 細線。
  - **淺色模式**：`--color-notebook-grid: rgba(0, 0, 0, 0.045)`（溫潤極淡暖灰色，清晰辨識但不搶文字主體）。
  - **暗色模式**：`--color-notebook-grid: rgba(255, 255, 255, 0.04)`（夜間極淡冷灰方格）。

### 2. 日系無酸手帳手感紙漿微粒 (`.paper-grain`)
- 格線底層鋪設無縫純向量 SVG 紙漿噪點（`feTurbulence`，透明度 3.5%），讓方眼格宛如印刷在真正的日系無酸手帳紙上，觸感細膩消光。

### 3. 夜晚書桌檯燈柔光聚光 (`Desk Lamp Ambient Spotlight`)
- 頂部中央散發柔和琥珀金漫射光暈（`radial-gradient`，透明度 6%）：
  - 營造出「在夜晚書桌檯燈下，翻開一本貼著和紙膠帶與門票歌單的 Official 髭男 dism 巡演手帳」的溫暖沉浸體驗。

---

## 後果 (Consequences)

### 正面影響 (Positive)
1. **擬物邏輯完美自洽**：手撕和紙膠帶貼在方格筆記本頁面上，形成了完全合情合理的「手帳剪貼簿」美學心智模型。
2. **視覺層次豐富且護眼**：方格紙線條極淡，搭配暖紙底色（`#f0eee8`）與柔光聚光，既不干擾大量曲目閱讀，又賦予全站極高辨識度的人文溫度。
3. **極致效能**：純 CSS 漸層與單一向量噪點，固定滿版零重繪，維持全平台 60fps 滑順滾動。
