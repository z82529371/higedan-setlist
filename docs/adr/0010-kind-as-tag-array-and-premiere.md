# kind 改為特別標籤陣列，新歌以巡演為單位標記

演出曲目上的 `kind` 從單一字串改為標籤陣列（`"kind": ["request"]`），同一項目可同時掛多個標籤（如點歌兼首唱）；渲染依標籤逐一掛徽章而非單一切換。

新增 `premiere` 標籤（展示文字「新歌」）：表示該歌在此巡演首次帶入演唱會曲庫，是**歌 × 巡演**層級的事實，直接標記在巡演模板的演出曲目上，故該巡演每次登場皆顯示。不做「單場初披露」的逐場標記語意——若某曲只是某一場首演，那不是此標籤的範圍。

`premiere` 只標記在巡演模板槽；diff 的 insert 項目暫不預設承載巡演層標籤。arrangement（改編演出）標籤暫緩，語意待確認後再補。ADR 0008 的曲目變更／點歌區分規則不變，request 仍只是標籤值。
