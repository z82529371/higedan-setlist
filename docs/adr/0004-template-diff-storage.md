# 同巡演場次以模板加差異存放

同巡演各場曲目高度重複，故巡演在 tours.json 獨立存放一份模板曲目清單，各場次僅存對模板的差異 ops（skip、insert、note），不再存全文；模板以巡演首場為準，暫缺時以已收場次為藍本並註明，模板一經更正所有依附場次須重算。

order 定為模板錨點而非顯示編號，解析後保留錨點號，網站顯示的第幾首於渲染時按位置另算。

note 僅記錄實質版本差異（如點歌段的部分演唱），標點空格等打字習慣差異一律歸一為模板寫法，不另存 op。

點歌段不進模板：模板只留共同骨架，各場點歌以 insert 自理（同錨定不同歌，如 Subtitle、115万キロのフィルム、日常皆錨定同槽）。

場次 id 為 {巡演}-{城市}-{MMDD}；同日同場館加開兩場時加時段後綴 -matinee（午場）／-evening（晚場）。

星期（weekday）與開演時間（opensAt）為場次選填欄位，有資料來源可考就填，沒有就空著，不為了填而填；星期用一二三四五六日，不用日式火水木金土。
