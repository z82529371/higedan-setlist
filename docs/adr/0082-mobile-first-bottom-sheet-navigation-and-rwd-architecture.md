# ADR-0082: 行動端浮動導航抽屜、雙向喚起與全站 RWD 人體工學架構 (Mobile-First Bottom Sheet Navigation and RWD Architecture)

* **狀態**：已採納 (Accepted)
* **日期**：2026-10-11
* **影響層面**：前台首頁 Header 與導航系統 (`site/src/App.jsx`)、全域搜尋框 (`site/src/components/SearchBox.jsx`)、舞台歌單票根單據 (`site/src/components/slips.jsx`)、全站領域模型 (`CONTEXT.md`)

---

## 背景與動機

1. **行動端四階導航縱向堆疊壓迫**：
   在 360px–430px 的手機直向螢幕中，場次分頁的「四階導航（演出類型、年份、活動、場次）」多行膠囊按鈕群展開後吃掉超過 400px+ 垂直空間，使用者必須滑動數屏才能看到核心的「現場舞台單據（Stage Run Sheet Slip）」。歌曲與場地分頁亦有類似的高度佔用問題。

2. **iOS Safari 輸入框自動放大破版**：
   原全域搜尋框輸入字級為 14px，在 iOS Safari 點擊聚焦時會強制觸發視窗自動放大（Auto-zoom），導致頁面橫向跑版；且下拉搜尋面板在虛擬鍵盤彈起時容易被遮蔽。

3. **操作工具列在窄螢幕破碎零散**：
   原歌單卡工具列將「產生紀念小卡」、「複製歌單」與多個分析折疊按鈕混雜於同一 `flex-wrap` 容器，在手機上折成 3～4 行破碎小按鈕，觸控熱區不足且視覺階層混亂。

4. **巡演場次翻閱操作摩擦力**：
   使用者在巡演專場翻閱各站歷史歌單時，若每次切換都必須重新捲動至頂部重新挑選按鈕，會大幅降低流暢感。

---

## 決策與架構規範

### 1. 行動端浮動導航抽屜（Mobile Filter Bottom Sheet）與雙向喚起
- **桌機手機分流**：
  - 桌機端（`>= 640px`）：維持單欄平鋪展開之四階/多階導航面版，一覽無遺。
  - 行動端（`< 640px`）：四階導航平日 100% 收納隱藏，讓出整屏空間給歌單單據。
- **雙向喚起入口（Dual Trigger）**：
  - 右下角常駐品牌金圓形浮動按鈕（FAB，`🏷️ 篩選場次` / `🎵 挑選歌曲` / `🏛️ 挑選場館`）。
  - 主畫面頂部提供「當前狀態摘要標籤條（Current Context Summary Bar）」，點擊同樣可平滑滑出抽屜。
- **暫存草稿機制與顯式確認送出（Staged Draft State & Explicit Confirmation Commit）**：
  - 抽屜支援內部垂直滾動、下拉手勢與點擊背景遮罩退出。
  - 徹底淘汰原「點擊末級選項立即自動收合關閉」的粗糙機制；打開抽屜時深度複製當前導航狀態為暫存草稿（`draftState`），在抽屜內探索、切換上層或點選任何末級項目時，僅於抽屜內部更新選中狀態與品牌金高亮，絕對不自動跳轉或收合抽屜，提供沉浸無打擾的挑選體驗。
  - 底部 Sticky 動作列採用雙按鈕結構：「取消（放棄暫存變更並退出）」與「確認套用（顯示目前暫存選取之場次/歌曲/場地名稱）」，點擊確認後一次性 Commit 路由變更、更新 URL Hash、收起抽屜並平滑滾動置中單據。
- **全站三大查詢分頁一致性（Universal Consistency）**：
  - 場次（四階抽屜）、歌曲（專輯/曲目抽屜）、場地（地區/場館抽屜）全面貫徹此互動模式。

### 2. 頂部 Header 與 Micro-Hero 自適應緊湊化
- 大標題在手機端自適應縮至 `clamp(24px, 6vw, 32px)`。
- 副標題在行動端精簡為單行。
- Micro-Hero 5 顆動態數據膠囊在行動端採單行水平滾動軌道（`-mx-4 px-4 overflow-x-auto scrollbar-none`），避免多行折疊推擠首屏。

### 3. 全域搜尋框行動端防縮放與視窗適配
- 搜尋框字級調整為 `text-[16px] sm:text-[14px]`，杜絕 iOS Auto-zoom。
- 搜尋結果下拉面板最大高度設為 `max-h-[48vh] sm:max-h-[380px]`，確保虛擬鍵盤彈起時浮層完整露在鍵盤上方。
- 選中項目後自動調用 `blur()` 收起虛擬鍵盤。

### 4. 歌單卡操作工具列主次兩段分流（Primary Row + Secondary Reel）
- **第一列（核心行動）**：並排設置「📸 產生紀念小卡」與「📋 複製歌單」雙核心大按鈕（觸控高度 38px+）。
- **第二列（分析折疊）**：記號圖例、曲目更換、專輯分佈、雙場對比收納為單行水平滑動標籤列（Chip Reel）。

### 5. 拇指友善巡演步進器（Touch-friendly Tour Stepper）
- 票根與單據底部的「← 上一場 / 下一場 →」步進按鈕加寬加高（40px+ 觸控熱區），巡演歌迷無需打開抽屜即可一鍵連續翻閱巡演歷史。

---

## 效益

1. **極致行動端首屏能見度**：手機進站後首屏即可立即望見實體歌單卡票頭，資訊獲取效率提升 300%。
2. **人體工學拇指友善**：右下角 FAB、底部抽屜與大按鈕熱區全面適配單手單指握持體驗。
3. **無損桌機體驗**：桌機依然享有 960px 容器內一覽無遺的清晰四階平鋪導航。
