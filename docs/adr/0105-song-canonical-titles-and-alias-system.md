# ADR-0105: 歌曲官方一手正名與雙語別名檢索架構（Song Canonical Titles and Dual-Language Alias System）

## Status
Accepted

## Context
1. **官方一手日文發行曲名英文化偏差**：
   在歷史建檔過程中，部分官方一手發行（日本實體 CD 及官方網站 DISCOGRAPHY）原始標題為日文片假名的歌曲，在資料庫中被英文化（例如官方發行為《ノーダウト》，資料庫記錄為 `No Doubt`；《イエスタデイ》記錄為 `Yesterday`；《ミックスナッツ》記錄為 `Mixed Nuts`；《ホワイトノイズ》記錄為 `White Noise` 等）。
2. **跨平台海外元資料差異與檢索盲區**：
   海外樂迷與使用非日本地區 Spotify / Apple Music 的使用者，在平台介面上往往看到的是發行商提供的官方英文譯名或英文字元標題（如 `No Doubt`、`Yesterday`、`Mixed Nuts`、`Stardust`）。當使用者在搜尋欄輸入 `No Doubt` 或 `Stardust` 時，因資料庫無別名對應，產生「搜不到歌」的體驗斷層。
3. **官方公信力邊界**：
   根據領域模型要求，全庫歌曲必須嚴格遵循官方一手命名原則，杜絕收錄民間自創簡稱或非官方暱稱。

## Decision
1. **歌曲主標題回歸官方一手正名（Canonical Japanese Title）**：
   - 歌曲主檔（`data/songs.json`）的 `title` 欄位嚴格回歸日本一手官方正式發行表記。
   - 共 14 首雙語對照曲目回歸正名為片假名主標題（如 `ノーダウト`、`イエスタデイ`、`ミックスナッツ`、`ホワイトノイズ`、`アポトーシス`、`パラボラ`、`ペンディングマシーン`、`ブラザーズ`、`バッドフォーミー`、`ビンテージ`、`ラストソング`、`キャッチボール`、`エルダーフラワー`、`スターダスト`、`フィラメント`、`イコール`）。
   - `sweet-tweet` 正名為官方全大寫 `SWEET TWEET`，`ai-nandaga` 維持官方正名 `愛なんだが…`，兩者不設別名。
2. **官方雙語別名（`alias`）欄位擴充**：
   - 在 `data/songs.json` 中擴充 `alias` 欄位，精準記錄發行商在海外數位串流（Spotify / Apple Music）使用的官方正式英文名稱（如 `No Doubt`、`Yesterday`、`Stardust` 等 16 首）。
   - 嚴格禁止收錄民間自創簡稱或非官方暱稱。
3. **歌曲詳情票根（`SongSlip`）別名呈現**：
   - 在歌曲大標題正下方以等寬灰字工藝風格呈現副標列：`別名：XXX`（`font-mono text-[13px] text-muted`）。
   - 點擊「複製歷史」時同步輸出包含別名之完整資訊。
4. **全域搜尋（`SearchBox`）即時雙向索引與標註**：
   - 搜尋引擎比對邏輯同時命中 `s.title` 與 `s.alias`。
   - 歌曲待選候選項目若具備別名，一律完整渲染 `別名：XXX` 副標，不論輸入日文或英文關鍵字皆可第一時間秒搜直達。

## Consequences
- 徹底解決「日文正式歌名無法搜尋英文別名」及「Spotify 英文標題搜尋不到日文曲目」的跨語言檢索斷層。
- 100% 保持官方一手唱片公信力，杜絕非官方民間自創名詞污染。
- 既有 53 項領域不變量與端對端測試完全相容相通。
