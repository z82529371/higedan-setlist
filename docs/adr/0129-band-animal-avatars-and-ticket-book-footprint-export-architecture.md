# ADR-0129: 團員動物吉祥物動畫、代表曲目廢除與個人參戰足跡明信片圖卡架構 (Band Animal Avatars, Representative Song Omission & Ticket Book Footprint Postcard Export Architecture)

## Status
已採納 (Accepted)

## Context
在 Issue #47（ADR-0124）之「Not yet specified」規劃中，曾列出四項待展開之領域迷霧：
1. 四位團員（藤原聡、小笹大輔、楢﨑誠、松浦匡希）代表動物角色之視覺設定、插畫風格與狀態表情設計；
2. 巡演載具（🚐 vs ✈️）之 SVG 向量動態插畫與路徑沿線轉向／起降特效；
3. 動畫播放控制器隨日期推進跳出當日場次小卡與代表曲目；
4. 個人巡演票夾（`TicketBookPage`）是否支援將「個人參戰足跡地圖」一鍵匯出為紀念圖卡（PNG）。

其中第 2 項（巡演載具動態與轉向起降）已於 Issue #53（ADR-0124）由 `TourVan3D` 與 `TourAirplane3D` 完整落地。然而剩餘 3 項在進入實作交付前，需要明確的領域模型（Domain Model）、視覺標準與邊界約束：

1. **團員動物角色與領域主客體混淆風險**：
   - 四位團員的象徵動物雖在官方訪談與樂迷社群中有深厚默契，但若未界定「登場介面邊界」，一旦將團員動物無差別置入歌迷個人票夾（`TicketBookFootprintMap`），會造成主詞錯亂（究竟是歌迷在參戰，還是樂團在巡演？）。
2. **「當日代表曲目（Representative Song）」的過度設計與主觀化約**：
   - 原草案構想在路線推進時隨日期跳出「當日代表曲目」。但在深入檢視使用場景後發現：一場 Live 是由 20 多首曲目交織而成的完整情緒旅程，硬挑單一首曲目既主觀且片面化約；且在 2x / 4x 動畫倍速播放下，曲目文字在 0.3 秒內閃爍掠過，只會帶來嚴重的視覺噪音與認知負擔；而現有地圖 HUD 已經具備直達單場完整歌單的 `SETLIST ➔` 門戶。
3. **樂迷遠征踏破記憶的空間缺口（The Fan Memory Trinity）**：
   - 目前票夾已有「單場紀念票根（`MemorialCardModal`，微觀現場）」與「生涯成就卡（`MilestoneCardModal`，曲庫解鎖）」，唯獨缺少日本樂迷極具自豪感的「空間遠征維度（日本 47 都道府縣制霸與移動軌跡）」。若直接塞入既有生涯成就卡，會造成圖片長度超過 1500px 嚴重變形；歌迷需要一張獨立、標準明信片比例的參戰足跡圖卡。

## Decision

### 1. 四位團員代表動物吉祥物（Band Animal Avatars）契約與三態巡演狀態機
- **官方與樂迷文化象徵對應**：
  - 🐨 **藤原聡（Vo/Pf）**：無尾熊（Koala），專屬符號為麥克風與琴鍵。
  - 🐱 **小笹大輔（Gt）**：貓咪（Cat），專屬符號為電吉他。
  - 🦍 **楢﨑誠（Ba/Sax）**：大猩猩（Gorilla），專屬符號為貝斯與薩克斯風。
  - 🐻 **松浦匡希（Drs）**：大熊（Bear / ちゃんまつ），專屬符號為鼓棒。
- **雙重呈現介面**：
  - **載具內部露臉**：於 `TourVan3D` 側窗與後座露出探頭小頭像（車前座 🐨🐱，後座 🦍🐻），隨車體切線角度平滑移動；`TourAirplane3D` 機窗透出動物剪影。
  - **抵達現場齊聚互動**：於地圖 HUD（`journey-hud-card`）旁浮現齊聚徽章。
- **三態巡演狀態機（Touring State Machine）**：
  - **`moving`（行駛/飛行中）**：車窗探頭，專注前行。
  - **`stay`（連日駐留）**：HUD 呈現休整充電模式（如 ☕ / 咖啡拉麵放鬆圖騰）。
  - **`arrived`（抵達現場）**：HUD 彈出四位動物手持各自專屬樂器齊聚歡呼；若為巡演終點站（`isFinal: true` / 千秋樂），追加彩帶與感謝慶祝表情。
- **嚴格領域登場邊界（Strict Domain Boundary）**：
  - **樂團主體專屬**：動物吉祥物與巡演載具**僅出現在**「單一巡演路線圖（`TourJourneyMapPanel`）」與「全生涯編年史長征（`JourneyPage`）」。
  - **個人票夾足跡嚴格排除**：個人票夾（`TicketBookFootprintMap`）代表「歌迷個人（Passport Holder）」的獨立參戰歷程，**嚴格不出現**團員載具與動物吉祥物，維持歌迷個人的主體性與純淨完成態足跡。
- **純前端純量感 SVG 架構**：
  - 於 `site/src/components/map/BandAnimalAvatars.jsx` 封裝原生向量組件，嚴格綁定設計系統 Token（`var(--color-ink)`、`var(--color-band)`），增量預算 `< 3 KB` gzip，杜絕外部圖檔依賴，保證 PWA 離線可用。

### 2. 果斷廢除「當日代表曲目（Representative Song Omission）」
- 正式從領域模型中廢除「播放推進時跳出當日代表曲目」之規格。
- 維持地圖 HUD 專注於「日期、場館、首尾站狀態、團員動物反饋」，並以高對比之 **`SETLIST ➔`** 作為唯一真理門戶，點擊即流暢滑入單場票根查看真實完整歌單。

### 3. 個人參戰足跡紀念明信片圖卡（Footprint Postcard Export）
- 於 `TicketBookFootprintMap` 標題列右側新增「`📸 儲存足跡卡`」按鈕（僅在有實體打卡場次時顯示，0 場時安全隱藏）。
- 建立專屬離屏匯出模態框 `FootprintCardModal.jsx`，以標準 540px 票券明信片比例（Postcard Ratio）輸出 PNG：
  - **頂部**：票夾專屬票根編號、持有者暱稱（Holder Name）、參戰歷程年份區間。
  - **中央**：高對比點亮之日本 47 都道府縣金色踩點地圖（含海外城市徽章與個人移動軌跡）。
  - **底部**：遠征里程郵戳（踏破縣市數、總場次、累計遠征距離 `~X km`、首戰與最新參戰場次）。
- 與單場紀念票根（現場）、生涯總結卡（曲庫）共同構築完整「樂迷記憶三位一體（The Fan Memory Trinity）」。

## Consequences
- **Positive**: 賦予巡演地圖生動之情感靈魂，四位團員動物吉祥物以復古票券向量風格完美融入載具與 HUD。
- **Positive**: 嚴格守護領域主客體邊界，確保樂團巡演敘事與歌迷個人足跡不產生混淆。
- **Positive**: 果斷剔除「代表曲目」過度設計，防止主觀化約與高速播放下的視覺噪音，維持系統純粹。
- **Positive**: 補齊歌迷遠征踏破的空間榮譽感圖卡，提供優雅的 540px 明信片 PNG 匯出。
- **Compliance**: 完全遵循 `ADR-0123` 零後端靜態純粹性、`DESIGN.md` 高對比墨水規範與 PWA 現場離線瀏覽不變式。
